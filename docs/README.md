# docs — 项目文档

面向人的分析与记录，**不进扩展包**（`.edaignore` 已排除 `/docs/`）。
日常维护入口仍是根目录的 [README.md](../README.md)（面向使用者的简明用法）与 [CHANGELOG.md](../CHANGELOG.md)（面向用户的版本变更摘要）。
开发 / 维护人员请读根目录的 [DEV.md](../DEV.md)（项目结构、构建、本地调试与实现细节）。
**每次改动两份更新日志都要写**：根 [CHANGELOG.md](../CHANGELOG.md) 面向用户（**每行不超过 60 字**，只写新增/修复/优化，不写解决方式与实现细节，不出现文件名），本目录 [开发日志.md](开发日志.md) 保留完整技术细节、实测数据与回归结论。

## 约定

- **过程性/一次性材料不要放这里**：测试脚本、样本、截图、数据 dump 都在 `Temp/`（见 `Temp/README.md`）。
- 新写分析类文档放本目录；与版本绑定的完成度报告放 `报告/`，被新版取代后移入 `报告/历史/`。
- 改了 `docs/` 下的内容不需要重新打包扩展（已排除），但要记得在 `README.md` / `CHANGELOG.md` 里留链接。
