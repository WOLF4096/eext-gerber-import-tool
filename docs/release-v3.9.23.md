- **下载**：`eext-gerber-import_v3.9.23.eext`（668 KB）
- **在线演示**：<https://wolf4096.github.io/eext-gerber-import-tool/iframe/ImportGerber.html> —— 不装扩展，浏览器里直接试
- **适用**：嘉立创 EDA 专业版 V2.2.45 ~ V4.x.x，全程离线运行，不联网

## 主要新增

- **标准版工程导出**：直接产出能在标准版里打开、编辑的工程；位号文字与相邻导线合并都已处理。
- **飞针标注**：把引脚编号、焊盘名称、元件位号、网络名写在对应位置，按顶层/底层拆开，方便对照飞针文件逐点核对。
- **物理网络名**：导入后自动生成网络，同一网络的焊盘、走线、覆铜连成一体，查断点、改板省事不少。
- **FPC 补强层**：识别 `*StiffenerLayer_*` 文件，保留材料与厚度并按层归位（只支持「通过源码导入」）。
- **专业版 4.x**：支持 4.x 源码导入，导入后即可编辑。
- **处理模式自动识别**：按文件内容判断来源，不用再手动选，减少选错导致的图形异常。
- **浏览器演示模式**：不装扩展也能打开页面导入、查看、导出，先试再用。

## 主要修复

- **覆铜**：负片覆铜被填成一整块实心铜（有短路风险）、孔被填死、拆分后整块不显示、相邻两块之间留细缝、圆弧边缘被削掉一小条。
- **焊盘与网络**：底层焊盘整层丢失、矩形与异形焊盘连不上导线却显示飞线、同一个网络出现两三个名字、内层隔离孔丢失。
- **坐标与单位**：英寸单位文件整体偏移到板外、槽孔长度被撑到上千毫米。
- **无标记文件**：没有私有标记的 Gerber，焊盘与导线全部丢失，只剩钻孔和填充。
- **文字与标注**：文档层尺寸标注整段丢失、标准版位号显示成方框、高分屏上文字与图形错位。
- **大板**：二十多兆的文件导入要几十秒、缩放拖动一顿一顿。

## 已知限制

- 宏（`%AM`）里的轮廓、热焊盘等少数基元，以及 `%SR` 重复块，暂未还原。
- 标准版不导出埋盲孔；FPC 补强只支持「通过源码导入」，图元导入不支持。
- 真彩图片图层是加密的，无法还原。

## 安装

1. 下载下方的 `eext-gerber-import_v3.9.23.eext`
2. 嘉立创 EDA 专业版 → 高级 → 扩展管理器 → 导入 → 选择该文件 → 已安装页面 → 找到本扩展 → 配置 → 全部勾选
3. 顶部菜单「导入 Gerber」打开主界面
