## 四、重要项（强烈建议，影响开源项目可信度）🟡

### 3. 无自动化测试 / CI

全项目没有 `.github/`、没有 CI 配置，回归全靠 `Temp/` 下的临时脚本人工跑。建议至少：

- 把关键校验脚本（`fill_ring_check` / `net_health` / `stdcmp` / `fill_drop_check` 等）整合成一条可重复执行的命令；
- 加一个最小 GitHub Actions：`node --check iframe/js/*.js` + `npm run build`，作为 PR 门禁。

### 4. 多语言近乎空白

`locales/` 下 `en.json` / `zh-Hans.json` 各只有 2 个 key（菜单「关于」和 SDK 版本）。主界面是硬编码中文 HTML，若目标用户就是嘉立创中文生态则**可接受**，但建议在 README 里明确「界面为简体中文」，或补全英文菜单。

### 5. 命名 G2PCB 未全量覆盖

`ImportGerber.html` 主界面 `<title>` 仍是「Gerber 查看 / Gerber 转 PCB / 导出PDF文件」，未含 G2PCB。若 G2PCB 是正式产品名，建议主界面标题也带上（非阻塞）。

### 6. 图元支持表准确性存疑

README 图元表把「丝印 / 文字」四个通道都写「支持」，但实际**标准版不输出丝印 STRING 文字**（只有元件位号走 `TEXT` 轮廓）。简化表述与真实能力有偏差，建议核对 DEV.md §4.2 的能力矩阵后修正。
