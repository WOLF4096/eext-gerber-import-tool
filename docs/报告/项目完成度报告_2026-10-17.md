## 一、结论摘要

| 维度 | 判定 | 依据 |
|---|---|---|
| 核心转换链路（解析 → 画布 / 文件） | **完备** | 8 类几何图元 × 4 个导出通道全部支持并实测 |
| 嘉立创专业版私有段 | **完备** | Pad / Via / Track / PolygonModel / Copper / Image / Text / Rect / Circle / DrillDrawing 全部识别 |
| 网络生成 | **完备（几何推断）** | 4 通道全接入，6 样本无误连/无多岛 |
| 标准版导出 | **有明确边界** | 不输出文字、位号、埋盲孔 |
| 扩展特性 | **未实现** | 真彩图片、FPC 补强、`%SR`、X2 属性 |
| 工程化 | **偏弱** | 有 100+ 手工验证脚本，但无自动化测试入口（无 `npm test`） |

**按 README 4.2 支持矩阵统计（16 项 × 4 通道 = 64 格，支持=1 / 部分=0.5 / 不支持=0）：**

> 已支持 **48.5 / 64 ≈ 76%**
> 其中「几何 + 网络」核心项 **36 / 36 = 100%**，缺口全部集中在文字/埋盲孔/组信息/扩展特性。

判定：**可作为 Gerber 逆向与格式互转的实用工具投入日常使用；不适合作为生产级 CAM 转换器**（与 README 的自我定位一致）。

## 三、功能完成度明细

### 3.1 完备（可直接使用）

| 能力 | 说明 |
|---|---|
| 文件导入 | zip 压缩包 / 多选 / 拖拽；飞针 `FlyingProbeTesting.json` 自动挂载 |
| Gerber 解析 | RS-274X 全指令、区域 G36/G37、LPC/LPD 极性、G85 槽孔、坐标格式自动识别 |
| 焊盘 | 11 类标准光圈 + 参数化宏（基元 1/4/5/20/21/22） |
| 过孔 / 插件盘判别 | 孔径 ≥0.6mm 且铜环 ≥0.25mm 判为 THT，规避「插件盘变过孔」 |
| 导线 / 圆弧 | 含整圆拆分（360° → 两段 180°）、圆弧离散做连通判定 |
| 覆铜 / 负片 | 暗区收集 + LPC 清区挖空 + Clipper 布尔差 → 逐块 FILL（keyhole 缝避免孔洞） |
| 填充环规整 | 去零长首段 + 显式闭合（修复标准版「画布正常、导入全丢」） |
| 宏光圈布尔 | 暗并集 − 清差集，统一多边形方向避免被当孔洞 |
| 网络生成 | 铜层焊盘/过孔/导线/圆弧/折线/填充连通分析 + 并查集；飞针 NET_NAME 优先 |
| 飞针标注 | 引脚编号 / 网络名称 / 元件位号三层，画布显示 + 位号写装配层 |
| PDF 导出 | 单页 / 分层 / 全层，DPI 可调 |
| 画布写入 | 源码注入（推荐，可撤销）/ 图元注入（大数据量会卡） |
| 界面与合规 | 用户协议门控、PCB 上下文检测、关于页、赞赏引导 |

### 3.2 有明确边界

| 能力 | 边界 |
|---|---|
| 标准版导出 | **不输出** 文字（STRING/TEXT）、元件位号、埋盲孔；丝印文字会丢失 |
| 图元导入通道 | 分组信息不支持；埋盲孔需先手动加规则；无法完全撤回 |
| 导出专业版 V2 | 分组不支持 |
| 宏光圈 | 基元 6（Moiré）/ 7（Thermal）未绘制；复杂表达式尽力而为 |

### 3.3 未实现

| 能力 | 影响 |
|---|---|
| 真彩图片 | 彩色 Logo / 彩色丝印图无法保留颜色 |
| FPC 补强 | FPC 专用结构无法还原 |
| `%SR` 步进重复 | 几何可解析，但复制阵列会被忽略 |
| Gerber X2 属性 `%TF`/`%TO` | 属性被忽略（层识别靠文件名与内容特征） |
| `PCB / FPC` 文档类型开关 | **UI 空壳**：仅改隐藏输入框与按钮高亮，不影响解析与导出 |

## 六、风险提示

1. **画布写入不可撤销**：图元导入通道无法完全撤回；源码导入可撤销但会覆盖当前文档。README 与协议均已提示，但这是最高风险操作。
2. **网络为几何推断**：飞线/短路判定基于几何连通，不保证 100%；无飞针文件时网络名为 `NET{n}`。
3. **大板性能**：数万图元走图元导入会卡顿；负片拆分在极端情况下耗时（已有 400ms 日志阈值）。
4. **版本兼容**：仅对嘉立创 EDA V2.2+ 导出的 Gerber 有保证；其它软件走 RS-274X 通用模式，兼容性不承诺。

---

## 七、建议的下一步

1. **（低成本高收益）** 把现有验证脚本收敛为 `npm run verify`，覆盖：填充环、网络健康度、标准版逐字段、铜层描边、A/B 回归。
2. **确认标准版文字能力**：若格式支持，补齐 STRING 输出；不支持则在 README 与 UI 明确提示（当前仅 README 提到）。
3. **处理 PCB/FPC 空壳开关**：要么接入（影响层叠/补强），要么从 UI 移除，避免误导。
4. **`%SR` 支持**：解析时展开阵列，属于解析器层的独立增量。
5. **宏基元 6/7**：补齐 Moiré / Thermal 绘制，提升异形焊盘覆盖率。
