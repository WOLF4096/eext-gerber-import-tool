**已定论的两条关键外部约束**（写进项目记忆，避免再踩）：
1. `pcb_MathPolygon.createComplexPolygon()` 的入参是「**多块**多边形数组」，**单环走它会返回 `undefined`** → 填充静默消失；
2. EDA 的填充用**非零环绕规则**（挖空环必须与外环反向才会被挖掉），奇偶规则不成立。

## 五、已知限制 / 设计取舍

| 项 | 说明 |
|---|---|
| keyhole 开缝 | 负片拆分后，被铜环整圈围死的孔洞会割一条 **0.01mm** 宽的缝接到区域外（"无孔洞表示"的固有代价），面积损失实测 **0.1~0.8%**，肉眼不可见 |
| 圆弧离散化 | 弦高容差 0.01mm（小圆按半径 1% 收窄）；填充里的圆弧会变成折线 |
| 新增依赖 | `iframe/js/clipper.js`（Clipper 6.4.2，Boost Software License，203KB，已随包发布） |
| 性能 | 负片拆分在 `consolidate` 内执行，最坏样本约 90~150ms（0802-2） |
| 数据模型 | 清区只从「包围盒重叠且非 island」的同层暗区里挖；不完整还原 LPD/LPC 的先后语义 |
| layerId 56 | 钻孔图层默认不勾选（`07-file-io.js:218`），其文字/图片默认不参与任何导出 |
| 死代码 | `exportForOther_Pro()` 空实现且不可达（唯一起点 `exportTarget:'other'` 的处理器 `ready:false`，路由先返回）；registry 的 pending 兜底分支同理用不到 |
