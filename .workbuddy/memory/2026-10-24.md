## 修复 GitHub Pages 全站白屏（资源 404）

**结论：Pages 没坏，是代码里资源路径写错。**

- 站点：https://wolf4096.github.io/eext-gerber-import-tool/ （public repo，has_pages=true，从 main 构建）
- 症状：`/iframe/ImportGerber.html` 返回 200，但**21 个 js/css 全部 404**；About 页同样坏。
- 根因：`iframe/ImportGerber.html` / `About.html` 里引用写成根域名绝对路径 `/iframe/js/xxx.js`。
  浏览器解析 → `https://wolf4096.github.io/iframe/js/xxx.js`（缺 `/eext-gerber-import-tool` 前缀）→ 404。
  项目站点是**子路径**部署，根绝对路径必然失效。
- 引入时间：`b888aaa`（2026-10-14「拆分代码」）。此前 UI 是内联 `<style>/<script>`，单文件自包含，所以 Pages 能跑；拆成 11 个文件时全写成绝对路径，从此白屏 10 天。
- 验证：线上 HTML 与本地 HEAD md5 完全一致 → 部署正常，纯粹是代码问题。
- 修复（已改，未提交）：**一律改相对路径**。
  - `iframe/ImportGerber.html`：20 个 `src="js/..."` + `href="css/style.css"` + 注释说明
