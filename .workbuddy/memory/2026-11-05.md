### 环境坑（下次直接用）

- 本机**没有 gh CLI**，Release 走 GitHub REST API（脚本模板 `Temp/gh_release.py`：查同 tag → POST 创建 → uploads.github.com 传附件）。
- `~/.gitconfig` 里 `http.proxy = 127.0.0.1:7897` 是**死端口**（当前未监听），直接 git 操作会报
  "Failed to connect ... over proxy"。→ 所有 git 命令加 `-c http.proxy= -c https.proxy=` 绕过，**实测直连 github.com / api.github.com 可用（200）**。
- 凭据存在 Windows Credential Manager（`git:https://github.com`，用户 WOLF4096），可这样取 token：
  `printf "protocol=https\nhost=github.com\n\n" | git credential fill`（会回显 password）。
  token 是 40 字符 classic PAT，仓库权限 admin。
- ⚠️ `releases/download/...` 的附件下载走 `objects.githubusercontent.com`，本机**直连与 13182 代理都超时**，
  无法用 curl 完整验证下载；API 层面可确认 asset 已存在、大小正确。浏览器端（有代理）正常。
